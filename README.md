## 🚀 Démarrage en 5 minutes

```bash
# 1. Clone
git clone https://github.com/KajarnakLOKOSSOU2008/softeng-lms.git
cd softeng-lms

# 2. Setup automatique
node scripts/setup.js

# OU manuellement:
cd frontend
cp .env.example .env.local
# → Ajoute tes clés Supabase dans .env.local
npm install
npm run dev
# Ouvre http://localhost:3000 ✅
```
